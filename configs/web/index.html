🔄 Update System

This will trigger the system update process which will:

  • Create a backup of the current configuration
  • Pull the latest code from GitHub
  • Update Docker container images
  • Restart services with new configurations

⚠️ Warning: Services may be briefly unavailable during the update.

🔐 Note: This feature requires admin authentication. Set the ADMIN_TOKEN environment variable in the IoT service for this feature to work.
